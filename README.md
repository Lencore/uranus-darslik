# Uranus ochiq videodarsi

Статический двухстраничный лендинг, готовый к публикации на GitHub Pages.

- `index.html` — посадочная страница и форма сбора лида.
- `lesson.html` — страница открытого видеоурока.

После успешной валидации форма отправляет имя, телефон и рекламные метки в настроенный webhook, а затем переводит посетителя на `lesson.html`. Относительная ссылка сохраняет работоспособность как на пользовательском домене, так и в подпапке проекта GitHub Pages.

## Настройка

Основные параметры находятся в конце HTML-файлов:

- `WEBHOOK` и `LESSON_URL` в `index.html`;
- `VIDEO_URL` и `CTA_URL` в `lesson.html`.

Для публикации через GitHub Pages выберите ветку `main` и папку `/ (root)` в **Settings → Pages**.
